Machine learning is a subset of artificial intelligence that focuses on enabling computers to learn from data.
Deep learning uses multiple layers of neural networks to learn hierarchical representations of data.
Transformers have revolutionized natural language processing with their attention mechanisms.
Self-attention allows models to relate different positions of the input sequence to each other.
The encoder-decoder architecture processes input sequences and generates output sequences.
Positional encoding provides information about the position of tokens in the sequence.
Multi-head attention allows the model to attend to information from different representation subspaces.
The feed-forward network applies two linear transformations with a ReLU activation function.
Layer normalization stabilizes training by normalizing the inputs to each layer.
Residual connections allow gradients to flow directly through the network during backpropagation.
Dropout is a regularization technique that randomly disables neurons during training to prevent overfitting.
Token embeddings map discrete tokens to continuous vector representations.
The decoder generates output tokens one at a time using previously generated tokens as context.
Temperature sampling controls the randomness of generated text during inference.
Beam search explores multiple hypotheses to find higher-quality output sequences.
Greedy decoding selects the highest probability token at each step for deterministic generation.
Training uses backpropagation to compute gradients and update model parameters.
The Adam optimizer adapts the learning rate for each parameter based on gradient history.
Learning rate scheduling adjusts the learning rate during training to improve convergence.
Batch normalization reduces internal covariate shift and stabilizes training.
Gradient clipping prevents exploding gradients by scaling gradients that exceed a threshold.
Cross-entropy loss measures the difference between predicted and actual probability distributions.
Perplexity evaluates how well the model predicts the test set on a character or token basis.
Validation loss monitored on a held-out validation set indicates model generalization ability.
Character-level tokenization represents text as a sequence of individual characters.
Byte pair encoding merges the most frequent pairs of bytes or characters iteratively.
Subword tokenization balances between character and word level granularity.
Vocabulary size affects model capacity and computational requirements.
Long-range dependencies are challenging for models with limited context windows.
Contextual embeddings depend on the surrounding context rather than being fixed for each token.
Transformer architecture has become the standard for modern natural language processing tasks.
